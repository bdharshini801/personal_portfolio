
# Dharshini.B — Portfolio

A responsive personal portfolio for a Computer Science and Engineering student, built using HTML, CSS, Bootstrap 5, and Vanilla JavaScript.

## Features

- Responsive layout for mobile, tablet, and desktop
- Dark and light themes persisted using localStorage
- OS color-scheme preference on first visit
- Animated role text
- Reveal-on-scroll animations
- Animated skill meters
- Project category filters
- Contact form validation and Formspree integration
- SEO and Open Graph metadata
- Keyboard focus styles
- Reduced-motion accessibility support

## Tech Stack

- HTML5
- CSS3
- Bootstrap 5 via CDN
- Vanilla JavaScript
- Bootstrap Icons
- Google Fonts

## Folder Structure

```text
portfolio/
├── index.html
├── style.css
├── script.js
├── README.md
└── assets/
    ├── profile-placeholder.svg
    ├── project-placeholder.svg
    └── resume.pdf
```

## Getting Started

1. Download or clone the project.
2. Open the project folder.
3. Open `index.html` in your browser.

For the best development experience, use the VS Code Live Server extension.

## Customization

- Update personal details in `index.html`.
- Change colors, fonts, and layouts in `style.css`.
- Modify animations and interactions in `script.js`.
- Replace placeholder images and resume inside the `assets` folder.
- Configure your Formspree endpoint in `script.js` to receive contact form messages.
